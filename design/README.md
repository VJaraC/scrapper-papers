# Carpeta de Diseño Arquitectónico (design/)

Esta carpeta debe contener exclusivamente los diagramas generados **durante la sesión presencial en aula**:

1. `structure.drawio`: Archivo editable creado en Draw.io (diagrams.net). Debe incluir:
   * **Diagrama de Clases (Estático):** Nombres de clases, atributos privados (`-`), métodos públicos (`+`), tipos y relaciones.
   * **Diagrama de Secuencia (Dinámico):** Flujo temporal de ejecución para las operaciones críticas.

2. `structure.svg`: Exportación vectorial obligatoria del diagrama.
   * En Draw.io: *Archivo $\rightarrow$ Exportar como $\rightarrow$ SVG...*
   * Debe guardarse en esta misma carpeta `design/structure.svg`.
